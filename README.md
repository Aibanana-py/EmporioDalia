# 🌸 Emporio Dalia
> Aplicación web *front-end* para un restaurante ficticio, caracterizada por una estética delicada [cite: 1].

## 📋 Sobre el Proyecto

Emporio Dalia es una plataforma web desarrollada para brindar una experiencia visual encantadora y amigable. El proyecto incluye tanto la construcción del sitio como el desarrollo de su propia identidad visual, destacando su logo protagonizado por una gata calicó y el diseño gráfico de un menú exclusivo de seis platos[cite: 1].

## ✨ Características y Secciones

El sitio está estructurado para que la navegación del usuario sea intuitiva, incluyendo las siguientes vistas:

*   **Página de Inicio:** Bienvenida y presentación de la esencia del restaurante[cite: 1].
*   **Galería de Productos:** Muestra visual del menú de seis platos con su respectivo material gráfico[cite: 1].
*   **Formulario de Login:** Interfaz de acceso para usuarios[cite: 1].
*   **Testimonios:** Reseñas de la comunidad[cite: 1].
*   **Preguntas Frecuentes (FAQ):** Sección dedicada a resolver las dudas más comunes de los visitantes[cite: 1].

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido del lado del cliente haciendo uso de:

*   **React:** Para el desarrollo de componentes e interfaz de usuario[cite: 1].
*   **HTML5:** Para la maquetación semántica del sitio[cite: 1].
*   **CSS3:** Para la estilización personalizada y lograr el ambiente *kawaii-chic*[cite: 1].

## 🚀 Instalación y Ejecución Local

Para visualizar el proyecto en tu entorno local, copia y pega el siguiente bloque de comandos en tu terminal. Se ejecutarán en orden:

```bash
# 1. Clona este repositorio
git clone https://github.com/Aibanana-py/EmporioDalia.git

# 2. Navega al directorio del proyecto
cd EmporioDalia

# 3. Instala las dependencias necesarias
npm install

# 4. Inicia el servidor de desarrollo
npm start
Nota: Si el proyecto fue inicializado con Vite, utiliza el comando npm run dev en lugar de npm start.

# 5. Abre tu navegador:
Ingresa a http://localhost:3000 (o el puerto que te indique la terminal) para ver el sitio en funcionamiento.```
